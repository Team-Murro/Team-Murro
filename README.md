## 🎯 철학 & 목표

> **"AI, 머신러닝, 자동화와 협력하여 — 극한의 자동사냥을 구현한다"**

인간이 잠든 사이에도 시스템은 스스로 학습하고, 판단하고, 실행한다.
반복 가능한 모든 것은 자동화하고, 자동화된 것은 AI로 고도화한다.
궁극의 목표는 **완전한 자율 시스템** — 사람의 개입 없이 돌아가는 자동사냥 머신.

```
사람이 설계한다  →  AI가 판단한다  →  시스템이 실행한다  →  ML이 진화한다
```
